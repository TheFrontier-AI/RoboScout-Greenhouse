# แผนงาน
1. (สัปดาห์นี้) ผังทางเดิน + ตัววางแผนภารกิจ + ตัวควบคุมเดินกลางทางเดินแบบกฎ พร้อม unit test — **เสร็จโครงแล้ว**
2. ต่อกับ R180 env: เดินหน้าถึงท้ายทางเดินกลางและหยุดหน้ากล่อง ด้วยเซนเซอร์เท่านั้น (ไม่ใช่ตำแหน่งจริง) วัดระยะขอบ
3. ขอ Astra ขยาย env: ถอยหลัง, จุดเริ่มสุ่ม, สิ่งกีดขวางหลายแบบ, เริ่มทุกทางเดิน, ส่งภาพทุก 0.5 ม.
4. เดินครบ 1 ทางเดิน (ไป–ถอย) 10/10 → เดินครบโรงเรือน (เฉพาะทางเดินที่ผ่านได้)
5. ต่อ central_brain (harness) ผ่านสัญญา INTERFACES_th.md และส่งภาพให้ทีม anomaly detection
6. ย้ายตัวควบคุมลง Jetson (ROS 2) และทดสอบกับหุ่นจริงหลังประกอบ
