# R181-S: หุ่น R1 รุ่นกล้องคู่ (ZED 2i)

สถานะ: **สเปกและซิมพร้อมใช้** (29 ต.ค. 2026). ตัวหุ่น รูปร่าง ล้อ เสา และกล้องข้าง เหมือน R180 ทุกอย่าง เปลี่ยนเฉพาะกล้องหน้า
ไฟล์หุ่นของ Astra ไม่ได้ถูกแก้ กล้องคู่ใส่ผ่าน session layer ตอนรันซิม

## สเปกที่เปลี่ยนจาก R180

| | R180 | R181-S |
|---|---|---|
| กล้องหน้า | RGB ตัวเดียว (ซิม 1280×720) | **Stereolabs ZED 2i Polarizer** (เลนส์ 2.1 มม.) |
| ภาพ | 1 ตัว | กล้องซ้าย-ขวา ห่างกัน **12 ซม.**, HD1080 ที่ 30 fps (2K ได้ที่ 15 fps) |
| มุมมอง | ~69° แนวนอน | 110° × 70° ก่อน rectify (หลัง rectify ที่ 1080p fx ≈ 1066 px, ~84° แนวนอน) |
| ความลึก | ไม่มี | 0.3–20 ม. (คำนวณจากภาพคู่) |
| IMU | IMU ของหุ่น | IMU ในกล้องอีกตัว (ไจโร + ความเร่ง, ~400 Hz) |
| อื่น ๆ | – | กันน้ำกันฝุ่น IP66, ฟิลเตอร์ลดแสงสะท้อนจากฟิล์มพลาสติก/ใบไม้, USB 3 |
| ตำแหน่งติดตั้ง | หน้าหุ่น | **จุดเดียวกับกล้องหน้าเดิม** (`/Robot/Physics_Base/Sensors/front_rgb`) |
| ราคากล้อง | – | ~US$549 จาก Stereolabs (ไม่รวมภาษีนำเข้า) |

LiDAR C1, ล้อ, ไจโรของหุ่น, กล้องข้าง 6 ตัว: เหมือน R180

## ความสามารถใหม่
1. **หาตำแหน่งในตัวหุ่นด้วย cuVSLAM** (NVIDIA, รันบน Jetson): stereo / stereo+IMU / RGB-D ใช้คู่กับ LiDAR
2. **สิ่งกีดขวาง 3 มิติ**: ความลึกเห็นของต่ำ/ห้อย (สายยาง, กิ่ง) ที่ LiDAR ระนาบเดียวไม่เห็น
3. **รายงานเหตุการณ์มีระยะจริง**: Cosmos Reason → HERMES ได้ระยะถึงคน/สิ่งกีดขวาง
4. **แผนที่ 3 มิติขนาดเมตรจริง** สำหรับ lingbot-map / MapAnything บนคลาวด์

ข้อ 2–4 ยังเป็นงานถัดไป ข้อ 1 ทดสอบแล้ว (ด้านล่าง)

## ผลทดสอบในซิม (29 ต.ค., เส้นทางจริงรอบ 3 ช่วงเมตรแรกของโรงเรือน 09, 30 วินาที, 450 ภาพคู่ที่ 15 Hz, 960×540)

| cuVSLAM | ตามได้ | คลาด RMSE | สเกล | ความเร็ว (RTX PRO 6000) |
|---|---|---|---|---|
| stereo | 450/450 | 3.8 มม. | 1.007 | 1,308 fps |
| stereo + IMU | 450/450 | 4.2 มม. | 1.008 | 646 fps |
| RGB-D | 450/450 | 6.4 มม. | 0.975 | 507 fps |

เทียบ: กล้องหน้าตัวเดียวของ R180 (cuVSLAM Mono, ทั้งเส้นทาง, 2 Hz) ตั้งต้นไม่สำเร็จ คลาด 15.8 ม.

**ข้อควรระวัง:** ภาพในซิมสมบูรณ์เกินจริง (ไม่มี noise, motion blur, rolling shutter, calibration คลาด, IMU ไม่มี noise) ช่วงทดสอบสั้น 5.7 ม.
ค่าจริงในโรงเรือนจะแย่กว่านี้มาก ต้องทดสอบทั้งเส้นทางและทดสอบกับกล้องจริงก่อนอ้างตัวเลข

## วิธีใช้ (บน VM ที่มี Isaac Sim 5.1)

1. render ข้อมูลกล้องคู่ตามเส้นทางจริงที่บันทึกไว้ (ไม่ได้ขับใหม่ แค่ render ใหม่):
   ```
   /isaac-sim/python.sh scripts/replay_route.py --rec <run>/rec --out <out> --from-step 334 --to-step 6476 --hz 30
   ```
   ได้ `cam0/ cam1/ depth0/ imu0/data.csv groundtruth.csv calib.json` (รูปแบบ EuRoC) ใส่ `--chase` เพื่อได้กล้องตามหลังทำ animation
   ความเร็ว ~1.1 วินาที/เฟรม ที่ 960×540; ทั้งเส้นทาง 30 Hz ที่ 1080p ใช้หลายชั่วโมง เลือกช่วงด้วย `--from-step/--to-step`
2. รัน cuVSLAM:
   ```
   python3 scripts/cuvslam_r181.py --data <out> --mode stereo|inertial|rgbd --out result.json
   ```
   ต้องติดตั้ง wheel `cuvslam` v17.0.1 (cu12, cp312) และไลบรารี CUDA 12 (`nvidia-cusolver-cu12` ฯลฯ) ใน LD_LIBRARY_PATH

ไฟล์ที่เกี่ยวข้อง: `sim/zed2i_rig.py` (สเปก + กล้องคู่ในซิม), `scripts/replay_route.py`, `scripts/cuvslam_r181.py`
